# 客厅派对问答（Android TV）

这是一个适合家庭成员一起参与的 Android TV 问答应用。  
核心设计目标：

- **遥控器友好**：只需方向键 + 确定键即可完整游玩
- **多人参与**：红队与蓝队轮流答题，客厅里可围坐讨论后作答
- **节奏清晰**：每题 20 秒，答对加分，回合自动轮换

## 玩法

1. 进入应用后选择「开始游戏」
2. 当前队伍会显示在顶部（红队/蓝队）
3. 使用遥控器移动焦点到选项，按确定提交
4. 题目结束后按「下一题」继续
5. 所有回合结束后显示胜负结果，可直接「再来一局」

## 构建命令

```bash
./gradlew clean test lintDebug assembleDebug
```

## APK 输出

`app/build/outputs/apk/debug/app-debug.apk`
